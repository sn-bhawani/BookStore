# 📚 BookStore Web Application

Welcome to the **BookStore** repository! This is a lightweight, full-stack web application featuring a clean separation of concerns. It uses a purely RESTful **Node.js** backend API to power a dynamic **AngularJS** frontend. The application manages a book catalog and integrates with the Garuda SMS API to instantly notify customers via WhatsApp/SMS upon inquiry.

## ✨ Features

* **Dynamic Book Catalog:** A beautifully rendered UI displaying books, authors, and prices, entirely managed via AngularJS data binding.
* **Instant SMS Notifications:** A Node.js API integration with Garuda SMS to send automated WhatsApp/SMS messages when a customer inquires about a specific book.
* **CORS & Error Handling:** Graceful frontend error handling for cross-origin requests, ensuring a seamless user experience even when third-party APIs block browser-based responses.
* **RESTful Architecture:** Clean, stateless communication between the AngularJS client and the Node.js server.

## 🛠️ Tech Stack

**Frontend:**
* [AngularJS](https://angularjs.org/) (Routing, Two-way Data Binding, Form Validation, `$http` requests)
* HTML5 / CSS3

**Backend API:**
* [Node.js](https://nodejs.org/) & [Express.js](https://expressjs.com/) (REST API endpoints)

**Third-Party APIs:**
* [Garuda SMS / WhatsApp API](https://garudasms.in/) (Messaging delivery)
